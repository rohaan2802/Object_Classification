Overview

CS-4090 Machine Learning for Robotics, Assignment 4, Spring 2026, FAST-NUCES, with Dr. Maryam Iqbal. The brief asked for a classification system a robot could use to tell objects apart from sensor readings, using KNN and Naive Bayes.

Dataset

500 synthetic sensor rows

125 rows each of metal can, plastic bottle, wooden block and rubber ball. Five features: distance, size, colour intensity, weight and sensor voltage. Each class has its own ranges. Seed 42, no missing values.

Models

KNN and GaussianNB

Features are scaled on the training set only. A 100-row stratified hold-out is used for the numbers below. After a small grid search both tuned models reach 100% on that test set.

Course

CS-4090 · Spring 2026

FAST-NUCES, roll 22I-2327. The assignment brief is in assignment/assignment-04.pdf. The write-up I submitted is in report/report.pdf.

The submitted report recorded 31% for both models. That run had trained on a first version of the table where labels were assigned at random, so the features had no relationship with the class. The scripts and notebook here train on the class-conditional table. The accuracies are high because weight and voltage already separate the four classes fairly cleanly — this is a clean synthetic table, not a claim about real sensors.

On this test set the two tuned models tie at 100%. GaussianNB was already perfect with its defaults; the search kept the default smoothing. I would pick GaussianNB if I had to choose one here — it is already at 100% without extra knobs, and it is cheaper to evaluate than an 11-neighbour KNN.

src/predict.py applies the scaler that was fitted at training time. The fitted models, scaler and label encoder are written together to models/object_classifiers.joblib when you run src/train.py. That file is left out of git on purpose — it is rebuilt in a few seconds.

How to Run

Python 3.10 or later. From the repository root:

Setup and train
python -m venv .venv
# Windows:  .venv\Scripts\activate
# Linux / macOS:  source .venv/bin/activate
pip install -r requirements.txt
python src/generate_dataset.py
python src/train.py
python src/predict.py --distance 40 --size 12 --color 180 --weight 400 --voltage 4.2 --model knn

generate_dataset.py is optional if you just want to reuse the CSV already in data/. train.py will also generate the table if the CSV is missing. The notebook is notebooks/object_classification.ipynb — it looks for src/ and data/ from the repository root or from notebooks/.

To preview this page locally, open index.html or serve the folder with python -m http.server 8080 and visit http://localhost:8080.
